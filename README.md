# flotta-teszt

Dummy end-to-end test page for the Marveen agent fleet workflow. No real
customer data, no backend: the contact form only shows a thank-you message.

- Stack: Vite + React + TypeScript
- Deploy: GitHub Pages via GitHub Actions, from the `main` branch
- Live: https://gergo91.github.io/flotta-teszt/

## Commands

```bash
npm install
npm run dev      # dev server
npm run lint     # oxlint
npx tsc -b       # type check
npm run build    # production build into dist/
```
